Plato v1 wireframes

Low-fidelity, desktop-first, from docs/v1/product-specification.md. Structure and flow only. Yellow notes cite the spec.

Build note: these sizes are approximate. In the app, follow shadcn/ui's standard design (this repo: base-nova style, neutral base colour, --radius: 0.625rem, lucide icons) for font sizes, spacing, padding, radius and components. Use the default type scale (text-sm body, text-xs meta, text-2xl/text-3xl headings), Tailwind's 4px spacing scale, and stock components (Button, Card, Tabs, Badge, Checkbox, RadioGroup, DropdownMenu, Sheet, Sonner toasts) rather than custom ones. Where a wireframe and shadcn differ, shadcn wins.

Navigation: sidebar with Today, Library and New request. Course pages have tabs. Sessions run full-window, without the sidebar.

A. Today

Home. One primary action: start a session.

B. Course request

One free-text box. No follow-up questions. Submitting returns you to Today.

C. Course page

Three tabs: Syllabus, Answers, Sources. The header (cover, title, course details, main button) stays on every tab.

D. Session

A session is reviews and learning, in one run sized to your length:

Every player screen uses one frame: top bar (× · title · time left · ⋯), a progress row, the question near the top, actions at the bottom.

E. Lesson steps

The progress row shows the five steps. Answers is dashed because it's optional. You can stop after any step.

F. Practice

Four exercise types are marked automatically. Short answers you mark yourself. All five use the same frame and the same feedback box.

G. Checkpoint & completion

Opens when a module's lessons are all completed. Practice first, then mastery. No final exam.

I. Phone

Single column, same components. Two tabs, and New request moves to a + in the header. Answer and next buttons sit at the bottom; tap targets are at least 44px.

J. Accessibility notes for hi-fi

Not drawn, but required.

  • Focus order in the player: options are a radio group (arrow keys), then Tab to the confidence buttons (shortcut keys 1/2/3). After submitting, focus moves to the result, then “In the brief”, then Next. Each new question focuses its heading.
  • Announcements (polite): the result after submitting; tick counts as they change (“3 of 6 recalled”, “Partly recalled”), even though they aren't shown on screen; step changes; toasts.
  • Time is a soft budget: nothing is cut off mid-step, there's no per-minute announcement, and ⋯ has a Hide timer option.
  • Names: × is “Exit session, progress saved”. Citation chips are “Source 2”. ≈ and ○ read as “Simplified” and “Not covered”. The length menu is a radio group.
  • State never by shade alone: lessons, steps, mastery and answers each carry a text label or symbol. Illustrations are decorative.
