A. Settings: ChatGPT connection

Settings sits at the bottom of the sidebar. ChatGPT is one row: logo, account, a status light and ⋯. Every action is in ⋯; ones you can't take now are greyed.

B. Request

Same box as v1, with Build course. If building can't start, a dialog says why and points to Settings.

C. Today and Library

Outside the build page you only see that a build is running, queued or paused. Never in the player.

D. Build page

The only place with stages and detail. Stages and their log in one terminal view. Cancel build lives in ⋯.

E. Operator

The same builder from the command line, on the operator's own ChatGPT connection. Command name is a placeholder.

F. Phone

Settings moves to a header icon. While building, a quiet line sits under the header.

G. Accessibility notes for hi-fi

v1's notes still apply. Added:

  • Announce (polite): build status and stage changes, not each log line or the “Last activity” time.
  • Status: every coloured dot has its word next to it; the dot is decorative. Stages are an ordered list, read as “Write, Fixing, try 2 of 3”.
  • Names: the light always has its status word (read aloud on phone). ⋯ is “ChatGPT actions”. Greyed menu items are announced as unavailable. Toast actions are also reachable from the build page.
  • Leaving for ChatGPT: those buttons say they open ChatGPT; on return, focus goes to the ChatGPT heading.
